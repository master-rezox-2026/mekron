# Francy China Item Online Shop

මෙම Zip ගොනුව තුළ **Francy China Item Online Shop** වෙබ් අඩවියේ සම්පූර්ණ ප්‍රභව කේත (Source Code) අඩංගු වේ.

## 📁 ගොනු ව්‍යුහය (Files Structure):
- `index.html` - ප්‍රධාන HTML සැකිල්ල සහ Modals (WhatsApp Checkout & Admin Panel)
- `style.css` - Animation, Custom Scrollbar සහ UI CSS Stylings
- `script.js` - WhatsApp Checkout, Item Codes, Search, Admin Operations & Supabase Storage Logic
- `README.md` - උපදෙස් පත්‍රිකාව

## 🚀 Netlify Hosting එකට Upload කරන ආකාරය:
1. මෙම Zip ගොනුව Extract කරගන්න.
2. [netlify.com](https://www.netlify.com) වෙත ගොස් Login වන්න.
3. **Sites -> Add new site -> Deploy manually** තෝරන්න.
4. Extract කළ folder එක Drag & Drop කරන්න. තත්පර කිහිපයකින් ඔබගේ වෙබ් අඩවිය Live වේ!
