# Mekron Engineer Website (Netlify & Supabase Deployment Guide)

## 1. Fast Deployment on Netlify (Static Hosting + Netlify Forms)
1. Login to https://netlify.com
2. Go to Sites -> Drag & drop the entire extracted folder.
3. Your site is instantly live!
4. Any form submissions will appear directly in Netlify Dashboard -> Forms.

## 2. Setting Up Supabase Database (PostgreSQL)
1. Create a free account at https://supabase.com
2. Create a project and go to SQL Editor.
3. Run the following query to create the table:

CREATE TABLE bookings (
  id bigint generated by default as identity primary key,
  name text not null,
  phone text not null,
  service text not null,
  address text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

4. Go to Project Settings -> API.
5. Copy 'Project URL' and 'anon public key' and paste them inside `script.js` (SUPABASE_URL & SUPABASE_KEY).
6. Upload the files back to Netlify!
